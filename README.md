# 🚀 AI Universe OS

AI Universe OS is an AI-powered workspace built with React, Vite, Node.js, Express, and Gemini API.

It provides a single workspace to manage AI agents, projects, analytics, and AI conversations.

## ✨ Features

- 🤖 AI Agent Management
- 💬 AI Chat powered by Gemini
- 🔄 AI Response Regeneration
- 📋 Copy AI Responses
- 🔎 Chat Search
- 📌 Pin Chats
- ✏️ Rename Chats
- 🗑️ Delete Chats
- 📊 Analytics Dashboard
- 📁 Project Management
- ⚙️ Settings
- 🌙 Dark Mode Settings
- 💾 Local Storage Persistence
- 📱 Responsive UI

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Recharts

### Backend
- Node.js
- Express.js
- Google Gemini API
- CORS
- dotenv
